## Ultrasonic Sensor Firmware 

HC-SR04 Ultrasonic Sensor

Range: 400cm
Practical Range: 100cm

The .ino file exists in `/src`, and most commands exist within `package.json`.

Build command: `pnpm arduino:compile`
Upload command: `pnpm arduino:upload`

With this, we can essentially flash many arduino UNOs.
The sensor views linearly, as in a vector. 

## Usage

We can build a firmware, and add few more ultrasonic sensors to create a navigation system for the blind.
if I were blind, and these were attached to all parts of the body, and then I get specific sound signals or even touch signals about incoming obstacles, I would be able to adapt quickly and move around

## What stops it from being popular:

"Do I look like a cyborg?" stigma. Blind people are humans too. They would rather die than live with an uncomfortable feeling of shame, even if that shame is within their own minds. 
- Other reasons involve: cost, but even that is fixable. What we need is to use empathy and try understanding how to make the blind feel included in the community.

- There exists many projects, like the smart cane designed by IIT Delhi. Pretty cool that community tries solving the issues.
